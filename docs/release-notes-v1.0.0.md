# Awake Time v1.0.0

第一个公开下载版本。下载后不需要 Xcode。

## 安装步骤

1. 在下方 `Assets` 下载 `Awake-Time-1.0.0-universal.zip`。
2. 不要下载 GitHub 自动生成的 `Source code (zip)`，那是开发用源码。
3. 双击 ZIP 解压，将 `Awake Time.app` 拖入“应用程序”。
4. 第一次打开时，按住 Control 点击应用并选择“打开”。
5. 如果 macOS 仍然拦截，进入“系统设置”→“隐私与安全性”，点击 Awake Time 对应的“仍要打开”。

下载包同时支持 Apple Silicon 和 Intel Mac，最低系统版本为 macOS 14。

## 说明

- 菜单栏显示太阳图标和个人醒时，例如 `☀ 04:37`。
- 时间从醒来记录开始，可以继续显示 `24:00`、`25:00`。
- 支持手动、自适应解锁、点击开始和每周预设四种模式。
- 数据只保存在本机，不需要账户或网络服务。
- 当前版本没有 Apple Developer ID 公证，所以第一次打开需要用户明确确认。

菜单栏空间不足时，请阅读 [Awake Time 与 Ice 教程](https://github.com/qian-123456/awake-time/blob/main/docs/ice-menu-bar-guide.zh-CN.md)。
